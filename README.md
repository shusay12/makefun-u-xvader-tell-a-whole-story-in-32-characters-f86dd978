An entry for the make.fun bounty [Tell a Whole Story in 32 Characters](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978?ref=susay21).

Running `main.py` (Python 3.13, standard library only, no network) writes
one original Wi-Fi network name (26 characters) to `/output/entry.txt`:

> TheWiFiOutlivedTheMarriage

A deadpan epitaph for a marriage: the couple, the divorce, and the router
still broadcasting afterwards. It implies a situation, characters, and
something that happened — a whole story in the few words a passer-by sees
in a phone's network list — and it is not one of the stock Wi-Fi jokes.
It runs identically every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
